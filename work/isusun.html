iSusun

A free, open-source, self-hosted Kanban board — built after running into the same wall on both Trello and Jira: useful extras locked behind a paywall, or open alternatives that never quite fit. Started from an open-source base and grown into a genuinely full-featured tool: time tracking, card linking, deadlines, an admin panel, Trello import, and a one-command Docker deploy.

  • Boards, templates, subtasks, time tracking
  • Card linking, activity log, comments
  • Role-based access, admin panel, Trello import
  • Fully offline mode, Docker-based deployment
