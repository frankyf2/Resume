MIRAR Platform

An enterprise training and compliance platform built end-to-end in Blazor Server for MIRAR (Malaysian Institute for Risk and Resilience). I own most of the system: certificate issuance and browser-generated PDF verification, an MCQ quiz engine with QR-coded live sessions and analytics, a survey engine spanning multiple client assessments (built out into a full Bank → Instrument → Session architecture), and the admin and member portals underneath it all.

  • Certificate system with public verification & bulk send
  • Quiz engine — QR sessions, live analytics, linked certificates
  • Survey/diagnostic engine for multiple client engagements
  • Admin portal, member portal, audit logging
Blazor Server · MariaDB/MySQL · EF Core · Cloudflare Workers
