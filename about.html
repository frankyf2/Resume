A bit about how I work.

I'm a full-stack developer working mostly in Blazor Server and .NET, based at Puncak Nilam Management Sdn Bhd (PNMS). From there I help build out several platforms — most notably MIRAR, where I own the certificate system, the quiz and survey engines, and the admin tooling that makes the rest of it manageable.

Outside client work I build things I actually want to use — iSusun because I got tired of paywalled Kanban features, star8892 as a full social platform for an alumni community, and Autumn Twilight because I wanted a proper web home for a text-based world.

I like systems that hold up under real use: consistent service-layer patterns, admin tools that don't fight the people using them, and code that's still readable after the third feature request changes the plan.

Standard stack across most of this: Blazor Server (.NET), MariaDB/MySQL with Entity Framework Core, hosted on Plesk and reverse-proxied through Cloudflare Workers. I also work with Python, Flask, PHP, and plain HTML depending on what a project calls for.
